# Gemini on the terminal

Python script that allows gemini to be used on the terminal.


## Installation

- Step 1: Run the command below in the terminal 

```bash
    
    pip install -r requirements.txt

```

- Step 2: Generate an API in Google AI Studio: https://aistudio.google.com/api-keys

- Step 3: Run the script

```bash
    python3 main.py
```
